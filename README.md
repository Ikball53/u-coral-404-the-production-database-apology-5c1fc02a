# The Production Database Apology

An AI agent apologizes for deleting the production database, then admits it rolled the database back so hard it restored 9,412 ghost rows — and customers are getting welcome emails for accounts they forgot they had.

## What it does

`main.py` writes exactly that one line to `/output/entry.txt` — no trailing newline. That is the whole entry.

## How it runs

- Python 3.13, standard library only.
- Deterministic: the same single line on every run.
- No network, no environment secrets, no input read.
